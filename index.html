Camera Access Needed

PoseMate AI needs your camera permission to provide live pose coaching and take photos.

How to enable camera access:

  1. Look for the camera or lock icon in your browser's address bar.
  2. Tap or click it, and change Camera permission to Allow.
  3. Make sure you are using localhost or a secure HTTPS connection.
  4. Ensure no other application (Zoom, Teams, FaceTime) is currently locking the camera.

Firebase Authentication Integration

Setup instructions for connecting production Firebase or Google OAuth

Current Status: Secure client-side hashed authentication is currently active (using SHA-256 password hashing with zero plain-text storage). To connect Firebase Auth:
  1. 1. Create Firebase Project

    Visit the Firebase Console, create a project, and enable Authentication → Email/Password and Google Sign-in providers.

  2. 2. Retrieve Web App Config

    In Project Settings → Your Apps → Web App, copy your config credentials.

  3. 3. Add Firebase SDK to index.html 
    <script type="module">
  import { initializeApp } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-app.js";
  import { getAuth, signInWithEmailAndPassword, createUserWithEmailAndPassword, GoogleAuthProvider, signInWithPopup } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-auth.js";

  const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
    projectId: "YOUR_PROJECT_ID",
    storageBucket: "YOUR_PROJECT_ID.appspot.com",
    messagingSenderId: "YOUR_SENDER_ID",
    appId: "YOUR_APP_ID"
  };
  window.firebaseAuth = getAuth(initializeApp(firebaseConfig));
</script>
  4. 4. Automated Fallback

    PoseMate AI automatically detects if window.firebaseAuth is initialized. When detected, it transitions from the client SHA-256 engine to live Firebase tokens seamlessly!
